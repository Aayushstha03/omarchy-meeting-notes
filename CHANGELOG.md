# Changelog

All notable changes to Meeting Notes are documented here.

## 1.0.0 - 2026-08-16

First public release.

- Capture timestamped notes with an author name
- Work the panel from the keyboard: Tab moves between the author field, the note field, and the save button
- Keep named meeting sessions, each in its own Markdown file
- Create, rename, switch, and recoverably delete sessions
- Name a new session `new-meeting DD/MM/YY` by default
- Write Markdown to a directory you choose
- Open the active meeting in Omawrite, with the default Omarchy editor as fallback
- Archive a deleted session and its Markdown file for recovery
